# 企业身份接入（企业微信 / OIDC）

`AUTH_MODE` 支持三种取值：`dev`（本地固定身份，仅限开发）、`wecom`（企业微信登录，**当前生产使用的模式**）、`oidc`（通用企业身份提供商）。租户、访问组和角色一律从服务端验证过的令牌读取，浏览器提交的字段不参与鉴权。

---

## 企业微信登录（生产）

```dotenv
AUTH_MODE=wecom
WECOM_CORP_ID=企业ID
WECOM_AGENT_ID=自建应用AgentId
WECOM_SECRET=自建应用Secret
WECOM_REDIRECT_URI=https://你的域名/api/auth/wecom/callback
WECOM_TENANT_ID=default
WECOM_ADMIN_USERIDS=userid1,userid2
WECOM_SUPER_ADMIN_USERIDS=userid1
WECOM_SESSION_SECRET=至少32字节的随机字符串
WECOM_SESSION_TTL_MINUTES=1440
```

### 登录方式

- **手机（企业微信内打开链接）**：走 `snsapi_base` 静默授权，无需用户确认，只在企业微信内置浏览器里生效。
- **电脑（浏览器扫码）**：走企业微信官方 `wwLogin` QR 组件（`GET /api/auth/wecom/qr-config` 提供配置），扫码后回调到 `WECOM_REDIRECT_URI`。

服务端签发一枚 HS256 JWT（`WECOM_SESSION_SECRET` 签名），claims 包含 `sub`（企业微信 userid）、`tenant_id`、`groups`（`dept_<部门ID>` 数组，来自企业微信通讯录部门）、`roles`。前端把它存进 `localStorage`，之后所有 API 请求带 `Authorization: Bearer <token>`。

### 角色解析

- `WECOM_SUPER_ADMIN_USERIDS` 命中 → 直接给 `super_admin`，绕过其余判断（服务器配置项，不是数据库数据，避免误删数据导致权限丢失）。
- 否则默认给 `user`，`WECOM_ADMIN_USERIDS` 命中再追加 `admin`。
- 数据库里通过"角色权限"页面分配的自定义角色（`UserRoleAssignment` 表）也会合并进来，但 `super_admin` 不能通过这条路径授予（`RoleService.assign_user_role` 直接拒绝，`resolve_roles()` 里还有第二道过滤兜底）。

### 部门树与访问隔离

`GET /api/wecom/departments` 拉取企业微信通讯录部门列表（含 `id`/`name`/`parent_id`，服务端缓存 5 分钟），前端渲染成可展开/收起的勾选树，用于：

1. 上传文档时设置"按部门隔离"（写入 `access_groups` 为 `dept_<id>`）；
2. 文档管理/编辑弹窗的部门选择；
3. `/api/knowledge-bases` 按调用者的部门过滤——非管理员账号只能看到自己有权限读取至少一份文档的知识库。

### 自建应用配置要点

- 需要在企业微信管理后台把服务器公网 IP 加入应用的 IP 白名单，否则调用凭证接口会报 `errcode 60020`。
- 域名需要按企业微信要求完成可信域名校验（下载校验文件放到指定路径）。
- 会话 TTL 到期后前端会清空 `localStorage` 里的 token 并重新展示登录二维码，用户需要重新登录。

## OIDC 接入（通用企业身份提供商，可选）

```dotenv
AUTH_MODE=oidc
OIDC_ISSUER=https://identity.example.com/
OIDC_AUDIENCE=enterprise-rag
OIDC_JWKS_URL=https://identity.example.com/.well-known/jwks.json
OIDC_TENANT_CLAIM=tenant_id
OIDC_GROUPS_CLAIM=groups
OIDC_ROLES_CLAIM=roles
```

服务端校验签名、颁发者、受众、过期时间及主体，并从令牌读取租户、访问组和角色。

项目的自动化预演会生成临时 RSA 密钥、启动本地 HTTP JWKS 服务并签发真实 JWT，验证正确令牌、缺失令牌、错误受众和缺失租户路径。运行 `pytest tests/test_auth_oidc.py` 即可复测。该预演验证接入机制，但不能代替企业身份租户中的撤权与目录同步验收。

---

## 上线验收（两种模式通用）

1. 普通用户不能上传、删除文档或审批工具，看不到"文档管理""角色权限"导航入口。
2. 用户只能检索公开文档和其访问组/部门内的文档；对应的知识库也不会出现在选择器里。
3. 跨租户文档、任务、审计和反馈均返回空或 404。
4. 过期、错误受众/签名、未知身份的令牌均返回 401，前端重新展示登录界面。
5. 身份目录（企业微信部门调整、OIDC 目录撤权）变化后，新令牌立即反映最新的访问范围；已签发的旧令牌在 TTL 到期前仍按签发时的部门快照生效，这是设计权衡（避免每次请求都同步查询企业微信 API），需要立即生效的场景应缩短 `WECOM_SESSION_TTL_MINUTES`。
